# SphereWeb3

SphereWeb3 - веб-платформа для игровых проектов Lineage 2.
Проект объединяет публичный сайт, личный кабинет игрока, донат-систему, форум, поддержку и административную панель для управления сервером, пользователями и контентом.

Backend написан на Go, frontend - на React и TypeScript.
Приложение работает с MySQL, отдает собранный frontend через Go-сервер и содержит встроенные инструменты администрирования, мониторинга и обновления.

## Возможности

- Регистрация, авторизация, восстановление сессии и управление профилем пользователя.
- Поддержка игровых аккаунтов, смены пароля, истории входов и публичных профилей.
- Личный кабинет игрока с балансом, складом предметов, доставкой предметов в игру и обменом валют.
- Донат-система с провайдерами платежей, курсами валют, бонусами, историей транзакций и webhook-обработкой.
- Промокоды, бонус-таймеры, стартовые наборы, реферальная система, подпольные игры.
- Новости, документация, правила, голосования и настраиваемые страницы сайта.
- Форум с категориями, разделами, темами, постами, реакциями, жалобами, банами, модерацией и автопереводом.
- Встроенная система поддержки с диалогами, файлами, изображениями и real-time обновлениями.
- Админ-панель для управления пользователями, ролями, правами доступа, складами, балансом и активностью.
- Управление игровыми серверами, настройками регистрации, статистикой онлайна и query-каталогами.
- Настройки шаблонов кабинета, меню, языков, email, уведомлений, Telegram и объявлений.
- Мультиязычность, i18n-каталоги и инструменты автоматического перевода.
- Аналитика, статистика посещений, tracking links и replay пользовательских сессий.
- DDoS-настройки, диагностические логи, мониторинг Linux/MySQL, GeoIP и просмотр ошибок.
- Мультисайтовость, SSL-сертификаты, редиректы и управление доменами.
- Файловый менеджер, SFTP/FTP-передача файлов, резервные копии серверов и центр обновлений.
- Импорт пользователей из SphereWeb2.

## Запуск

1. Скачайте архив проекта.
2. Распакуйте архив.
3. Откройте терминал и перейдите в каталог приложения.
4. Выберите исполняемый файл для своей операционной системы и архитектуры.

В архиве релиза находятся исполняемые файлы под разные операционные системы и архитектуры.

### Windows

Запустите файл:

```bash
SphereWeb-windows.exe
```

### Linux

Проверьте архитектуру сервера:

```bash
dpkg --print-architecture
```

Если архитектура `amd64`, выдайте права на запуск и запустите приложение:

```bash
sudo chmod +x ./SphereWeb-amd64
sudo chmod +x ./updater-amd64
nohup ./SphereWeb-amd64 &
```

Если архитектура `arm64`, используйте файлы для ARM:

```bash
sudo chmod +x ./SphereWeb-arm64
sudo chmod +x ./updater-arm64
nohup ./SphereWeb-arm64 &
```

> Важно: SphereWeb запускает собственный встроенный веб-сервер. Если на сервере уже работает Apache, Nginx или другой веб-сервер, который занимает порты `80` или `443`, возникнет конфликт. В этом случае освободите нужные порты или остановите другой веб-сервер.
Если необходимо чтоб Ngnix работал, тогда запустите SphereWeb на другом порту.
Тогда создайте файл /data/config/tls.json с этим содержимым
```
{
  "http_port": "80",
  "https_port": "443",
  "plain_port": "80"
}
```
и замените на другие порты.
