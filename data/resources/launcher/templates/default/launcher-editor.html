Предпросмотр JSON

Следите за итоговой конфигурацией в реальном времени. При необходимости вы можете вставить собственный JSON в поле ниже и применить его к форме. 💡 Совет: Используйте кнопку "Открыть предпросмотр лаунчера" ниже, чтобы увидеть как будет выглядеть лаунчер с этими настройками!

Базовая информация

Заполните версию лаунчера и ссылку на актуальный установщик. Эти значения считываются для проверки обновлений и отображения пользователю.

Download

Ссылки на CSV-файлы и каталоги с архивами. Лаунчер перебирает CSV по списку до первого успешного ответа, после чего скачивает архивы.

Общие настройки

Настройте поведение лаунчера. Тип загрузки определяет, как будут распределяться загрузки между серверами.

Кнопки запуска игры

Настройте кнопки запуска. Для каждой кнопки укажите переводы, исполняемый файл, аргументы и цепочку триггеров (например, копирование файлов перед стартом).

Переводы

Определите, откуда копировать локализации после обновления. Если указан флаг default, при отсутствии выбранного языка будет использован соответствующий путь.

Новости

Управляйте новостной лентой для каждого языка. Все поля необязательны, но имя и описание помогут пользователю ориентироваться.

Post-update триггеры

Эти действия выполняются автоматически после успешного обновления файлов. Например, translationPaths скопирует переводы.

Подсказки: сохраняйте резервные копии launcher.json перед редактированием, проверяйте пути с учётом структуры клиентской папки и используйте F2 для быстрого возврата в редактор. Все изменения в форме моментально отражаются в JSON-предпросмотре.

Выберите язык

Добавьте локализацию для нового поля. Повторяющиеся языки недоступны.
